# 🌍 Portfólio Profissional - Carlos Augusto Venturini

Projeto desenvolvido para apresentar meu perfil profissional, formação acadêmica, habilidades técnicas e principais projetos na área de **Desenvolvimento de Sistemas**, utilizando **HTML5**, **CSS3** e **Bootstrap 5**.

---

## 🎯 Objetivo

Aplicar na prática os conceitos fundamentais de desenvolvimento front-end e design responsivo, criando uma página web moderna, organizada e navegável:
* **Estruturação:** Uso de tags HTML5 (`<nav>`, `<section>`, `<footer>`) para organizar o conteúdo de forma clara.
* **Estilização e Responsividade:** Combinação de CSS interno personalizado com o sistema de *grid* e componentes prontos do **Bootstrap 5.3.3** (Navbar fixa, Carrossel com transição *fade*, Cards e Badges).
* **Iconografia:** Integração da biblioteca **Devicon** para representar visualmente as tecnologias e ferramentas utilizadas.
* **Ambiente de Desenvolvimento:** Codificação e organização de arquivos utilizando o **VS Code**.
